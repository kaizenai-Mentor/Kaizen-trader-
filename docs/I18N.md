# KAIZEN i18n — owner directive, 13 Oct 2026

KAIZEN speaks five languages across the ENTIRE app: **English, French,
Chinese (Simplified), Japanese, Afrikaans**. The switcher lives in the
navbar on every page (and on the welcome onboarding bar). The choice is
sticky (cookie `kaizen_lang`, one year), falls back to the user's
`preferredLang` recorded at registration, then to `Accept-Language`.

## The three contracts

1. **Stored VALUES stay English.** Journal text, rule text, outcomes
   (`Win`/`Loss`/…), quick-check values (`YES`/`NO`), DB content — always
   English. Only interface chrome is translated. This keeps records
   machine-readable and comparable across languages forever.
2. **Machine blocks stay English.** `EXTRACTED:` (aiCoach) and
   `PSYCH-STATE:` (psychCoach) lines are parsed by code. Coaches are
   instructed to write them in fixed English format in every language.
3. **Long-form = owner-curated pass.** Legal body text (Terms, Privacy),
   the marketing paragraphs on the welcome page, and other long prose are
   NOT machine-translated. They stay English until the owner runs a
   curated translation pass. Titles and short copy are localized now.

## Architecture

| File | Role |
|---|---|
| `config/locales/{en,fr,zh,ja,af}.js` | The five dictionaries (key parity enforced by `test/locales.test.js`) |
| `config/locales/index.js` | `t(lang, key, params)`, `normalize`, `LANGS` — en fallback for unknown keys |
| `middleware/i18n.js` | Resolves request language; exposes `res.locals.t`, `res.locals.lang` |
| `views/partials/lang-switch.ejs` | The picker (navbar + onboarding bar) |
| `models/User.js` | `preferredLang` enum `en|fr|zh|ja|af` |

## Adding a string

1. Add the key to `config/locales/en.js` (source of truth).
2. Add the SAME key to `fr.js`, `zh.js`, `ja.js`, `af.js` — the locale
   test fails on any missing or extra key.
3. Use `<%= t('your.key') %>` in views. Params: `t('key', { name: x })`
   substitutes `{{name}}`.

## Owner-curated pass (remaining)

- `views/privacy.ejs`, `views/terms.ejs` — full legal body per language.
- `views/welcome.ejs` — the two hero paragraphs.
- Any sentence a lawyer or marketer would own.

Everything else on the site — chrome, the full session loop (plan →
record → reflect → detail), tools, support, chart menu, legal titles — is
already in all five languages.
