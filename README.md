# KAIZEN — AI Trading Discipline Mentor

KAIZEN is an AI-powered trading discipline platform 
that analyzes trader journal entries using Claude AI, 
identifies behavioral patterns (FOMO, revenge trading, 
rule violations), scores discipline sessions, and 
delivers personalized coaching.

## Features
- AI journal analysis powered by Anthropic Claude
- Discipline Score tracking (process, not P&L)
- Psychology sessions for mindset work
- Dual on-chain reputation: Zero Authority DAO + Mantle
- TradingView-integrated charting
- Achievement badges and community leaderboard

## Tech Stack
Node.js · Express · MongoDB Atlas · EJS · Solidity
